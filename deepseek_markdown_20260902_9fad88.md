# PropertyHub BD - Full Stack Real Estate Marketplace

A complete real estate marketplace for Bangladesh with authentication, property listing, favorites, and admin features.

## Features

- ✅ User Authentication (JWT)
- ✅ Property CRUD Operations
- ✅ Favorites/Wishlist
- ✅ Property Approval System
- ✅ Role-based Access (User/Agent/Admin)
- ✅ Dark Mode
- ✅ Mobile Responsive
- ✅ MongoDB Database

## Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Node.js, Express.js
- **Database:** MongoDB with Mongoose
- **Authentication:** JWT + bcrypt
- **Deployment:** Vercel/Render
